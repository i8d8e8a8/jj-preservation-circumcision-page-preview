# 기존 홈페이지 일반 페이지 통합 안내

## 목적

포경수술 콘텐츠만 새 디자인으로 교체하면서 JJ비뇨기과 홈페이지의 공통 PHP 프레임과 기능은 그대로 유지합니다.

보존 대상은 모바일 메뉴, 데스크톱 우측 퀵바, 로그인·회원가입 링크, 이벤트·상담·예약·오시는 길, 하단 상담 폼, 병원 정보와 푸터입니다.

## 중요한 원칙

`/child/sub/surgery2/2.php` 전체를 Next.js의 `index.html`로 교체하면 안 됩니다. 그렇게 하면 서버에서 생성되는 회원·상담·예약 기능과 공통 메뉴가 사라집니다.

1. FileZilla에서 운영 서버의 기존 `/child/sub/surgery2/2.php`를 먼저 내려받아 백업합니다.
2. 기존 파일의 헤더·메뉴·서브 비주얼·상담 폼·푸터 PHP 코드는 유지합니다.
3. 기존 본문 컨테이너 내부 내용만 지우고 `embed-snippet.php`의 코드를 삽입합니다.
4. 정적 빌드 결과물은 `/child/sub/surgery2/circumcision-assets/`에 업로드합니다.
5. PC와 모바일에서 메뉴, 우측 퀵바, 상담 폼 제출, 전화·카카오 링크를 확인합니다.

## 왜 iframe을 사용하는가

현재 콘텐츠는 독립적인 반응형 스타일과 모션을 포함합니다. 기존 홈페이지 CSS와 직접 합치면 양쪽의 전역 선택자가 충돌할 수 있습니다. 같은 도메인의 iframe으로 본문만 분리하면 기존 홈페이지 기능을 유지하면서 스타일과 모션 충돌을 막을 수 있습니다. 포함된 스크립트가 콘텐츠 높이에 맞춰 iframe 높이를 자동으로 조정하므로 내부 스크롤바는 나타나지 않습니다.

## 실제 반영 전 필요 자료

운영 서버에서 내려받은 원본 `2.php`가 있으면 공통 프레임의 정확한 시작·종료 지점을 확인해 최종 통합본을 만들 수 있습니다. 원본 없이 서버 PHP include 경로를 추측해 새 `2.php` 전체를 만드는 것은 피해야 합니다.
