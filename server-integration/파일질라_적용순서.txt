JJ비뇨기과 포경수술 일반 페이지 적용 순서
=========================================

적용 주소
https://jj-man.co.kr/child/sub/surgery2/2.php

핵심 원칙
---------
기존 2.php 전체를 새 index.html로 덮어쓰지 않습니다.
기존 PHP 프레임과 기능은 유지하고 본문만 교체합니다.

1. 서버 원본 백업
----------------
FileZilla 오른쪽 원격 사이트에서 다음 폴더로 이동합니다.
/child/sub/surgery2/

현재 2.php를 PC로 내려받아 다음처럼 별도 보관합니다.
2.php.before-circumcision-page-20260810.bak

가능하면 같은 폴더의 1.php도 내려받습니다. 1.php는 기존 정관수술 일반 페이지의 공통 구조를 확인할 때 사용합니다.

2. 정적 본문 업로드
------------------
이 패키지의 다음 폴더를 서버에 그대로 업로드합니다.

child/sub/surgery2/circumcision-assets/

업로드 후 다음 주소가 열리는지 확인합니다.
https://jj-man.co.kr/child/sub/surgery2/circumcision-assets/index.html

3. 기존 2.php 본문만 교체
-------------------------
서버에서 내려받은 원본 2.php를 편집합니다.

유지해야 하는 부분:
- 공통 head 및 header include
- 모바일 전체 메뉴
- 서브 비주얼
- 우측 퀵바
- 하단 상담 신청 폼
- 병원 정보와 footer include
- 기존 공통 JavaScript

기존 포경수술 설명이 들어 있던 본문 컨테이너의 내용만 지우고
본문삽입코드.php의 내용을 그 자리에 붙여 넣습니다.

주의: 본문삽입코드.php 파일 자체를 서버 include 할 필요는 없습니다.
코드를 원본 2.php의 본문 위치에 붙여 넣는 방식이 가장 단순합니다.

4. 검수
-------
- PC: 우측 퀵바 클릭 확인
- 모바일: 전체 메뉴 열림/닫힘 확인
- 로그인, 회원가입, 온라인 상담, 예약, 오시는 길 확인
- 하단 상담 폼 제출 확인
- 카카오톡 및 전화 링크 확인
- 새 본문 내부에 별도 스크롤바가 생기지 않는지 확인
- FAQ를 열고 닫을 때 다음 섹션과 겹치지 않는지 확인

5. 문제 발생 시 복구
--------------------
서버의 수정된 2.php를 삭제하고 백업한 원본 2.php를 다시 업로드합니다.
circumcision-assets 폴더는 본문에서 호출하지 않으면 홈페이지 기능에 영향을 주지 않습니다.

최종 통합 권장
--------------
서버에서 내려받은 원본 2.php를 Codex에 전달하면 본문 시작과 종료 위치를 확인해
붙여넣기까지 완료된 최종 2.php를 별도로 제작할 수 있습니다.
