## FileZilla 적용 순서

1. 서버의 `/child/sub/surgery2/` 폴더로 이동합니다.
2. 기존 `2.php`를 로컬에 내려받고 날짜가 포함된 이름으로 추가 백업합니다.
3. 기존 `circumcision-assets` 폴더가 있다면 삭제하지 말고 이름을 변경해 보관합니다.
4. ZIP의 `circumcision-assets` 폴더 전체를 먼저 `/child/sub/surgery2/`에 업로드합니다.
5. 전송 완료 후 ZIP의 `2.php`를 `/child/sub/surgery2/2.php`에 덮어씁니다.
6. 실제 주소를 데스크톱과 모바일에서 확인하고, 이전 화면이 보이면 강력 새로고침합니다.

## 롤백

문제가 생기면 새 `2.php`와 `circumcision-assets`를 비활성 이름으로 변경하고, 백업해 둔 기존 `2.php`와 자산 폴더 이름을 원래대로 복원합니다.

## 다시 빌드할 때

```powershell
$env:STATIC_BASE_PATH='/child/sub/surgery2/circumcision-assets'
pnpm run build:pages
```
