# 포경수술 일반 페이지 전환 기록

## 결정 사항

- 포경수술 콘텐츠를 독립 랜딩페이지가 아닌 JJ비뇨기과의 일반 진료 페이지로 취급합니다.
- 운영 주소는 `/child/sub/surgery2/2.php`를 유지합니다.
- 기존 홈페이지의 모바일 메뉴, 서브 비주얼, 우측 퀵바, 하단 상담 폼, 푸터를 보존합니다.
- 새 디자인은 공통 프레임 사이의 본문 영역에만 삽입합니다.
- GitHub 저장소와 설명에서 `랜딩페이지` 명칭을 제거합니다.

## 저장소 명칭

- 검수용: `jj-preservation-circumcision-page-preview`
- 소스·운영 백업: `jj-preservation-circumcision-page`

## 운영 안전 기준

원본 `2.php`를 먼저 내려받아 보관한 뒤, 본문 영역만 교체합니다. 회원, 상담, 예약 기능에 필요한 서버 PHP 코드는 정적 결과물로 덮어쓰지 않습니다.
